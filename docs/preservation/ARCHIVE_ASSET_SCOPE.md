# Archive Asset Scope

> Review map for original, generated, wrapper-only, and external DieAI assets.

_Current as of: 2026-05-30_

---

## Purpose

Use this note to understand what each committed artifact represents before reviewing,
redistributing, rebuilding, or pruning the archive. It complements the checksum manifest in
[Artifact Metadata](./ARTIFACT_METADATA.md) and the build-path details in
[SWF Provenance And Rebuild Notes](./SWF_PROVENANCE.md).

This is a preservation-scope note, not a full license clearance. The bundled GreenSock ActionScript
source still has a separate active licensing review.

## Rebuild Inputs

The minimum rebuild-oriented archive surface is:

- `DieAI.fla`
- `lib/shoot/*.as`
- `com/greensock/**`

The FLA publish profile emits `DieAI.swf` and `DieAI.html`; the tracked exported copies live under
`assets/`. The screenshots under `assets/images/` and the modern web wrapper are not required for an
Adobe Animate rebuild, but they are required for the current GitHub Pages revival experience.

## Runtime Surface

The current public page uses three layers:

1. `index.html` renders the static page, local-file guard, player frame, fallback UI, and screenshots.
2. The pinned external Ruffle runtime emulates Flash in the browser.
3. `assets/DieAI.swf` provides the preserved playable game content.

The Ruffle runtime bytes are intentionally not committed. The current decision and vendoring trigger
live in [Ruffle Runtime Decision](./RUFFLE_RUNTIME_DECISION.md).

## Review Checklist

Before changing archive contents:

- Confirm whether the file is an original game artifact, exported artifact, wrapper-only helper, or
  documentation evidence.
- Preserve `DieAI.fla`, `assets/DieAI.swf`, `lib/shoot/**`, and `com/greensock/**` unless an explicit
  replacement or licensing decision exists.
- Keep `assets/DieAI.html` as legacy export evidence unless a new publish pass intentionally updates
  it.
- Run `node scripts/smoke-wrapper.mjs` after wrapper, SWF, or image changes.
- Regenerate [Artifact Metadata](./ARTIFACT_METADATA.md) after committed artifact changes that alter
  bytes, counts, or hashes.
- Keep generated QA screenshots and traces outside the repository unless they become intentional
  baseline artifacts.

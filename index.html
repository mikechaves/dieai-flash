DieAI

A 2018 Flash game revived with Ruffle so the original SWF can run in modern browsers. Stop AICorp's Buddy Bots before the launch gets out of control.

Loading Ruffle player

The game loads the original Flash build through Ruffle. Click the player once if keyboard input is not active.

Controls

  • WASDMove around the arena
  • ArrowsAlternate movement controls
  • SpaceAttack and interact
  • EscPause or restart

Ruffle emulates the Flash runtime in WebAssembly, preserving the original ActionScript game without a browser plugin.

Game Screens

DieAI keeps its original Flash-era artwork, chunky type, neon grid, and robot factory setting intact.

Preserved as a Playable Artifact

This project keeps the original source files, ActionScript classes, GreenSock dependency, exported SWF, and modern web wrapper together so the game remains inspectable and playable.

The browser page is deliberately lightweight: static HTML, no build step, and a hosted Ruffle runtime.
